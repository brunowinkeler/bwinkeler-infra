# Prompt archive

Verbatim records of the chat prompts that started or shaped a project. They are
kept because they document intent that never made it into a requirement or ADR.

Two rules apply only to this directory:

- the files are **untranslated**; the platform language policy covers authored
  documentation, not transcripts, and rewriting a transcript destroys its value
  as a record;
- they are **not** a source of truth. Requirements live in each repository's
  `docs/REQUIREMENTS.md`, decisions in its `docs/ADR/`, and operational state in
  [`../../inventory.md`](../../inventory.md).

They stay in this private repository rather than in the public product
repositories.
